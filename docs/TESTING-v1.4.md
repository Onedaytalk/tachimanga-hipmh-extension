## 功能與操作

在來源設定新增「漫畫語言」，可選「不限語言（原始排序）」、「優先簡體中文」、「優先繁體中文」。預設維持原始排序。

搜尋、人氣與最新列表每頁內優先顯示所選語言，保留其他版本與各組原始順序。切換後請重新整理列表。已加入書庫的漫畫與章節維持原版本；需要換成另一語言版本時，可使用 Tachimanga 的來源遷移功能選擇對應作品。

## 第一次查詢與快取

網站清單與搜尋 API 不提供語言欄位，也未套用測試的語言參數，因此需讀取作品資料的實際語言標記。來源只快取最多 512 筆作品編號對應的短語言代碼，不快取完整作品或章節資料。

本次第一次簡體優先搜尋讀取 17 筆語言資料，約 6.97 秒；接著切換繁體優先時，額外語言查詢為 0，整次搜尋約 0.022 秒。保留原始排序時不增加語言查詢。快取存在於來源實例，重新建立實例後會依需求重新讀取。
